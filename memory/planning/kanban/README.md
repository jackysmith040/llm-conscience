# 📋 The Kanban Board

This directory is used by the **Orchestrator** persona and the `senior-stable-delivery` / `pipeline` skills to track complex, multi-step execution tasks. 

When the OS enters `[STATE 4: MOTOR_EXECUTION]` for a large project, the AI will autonomously create markdown files here (e.g., `feature_x_board.md`) to track To-Do, In-Progress, and Done items. 

*Note: This file ensures the directory is tracked by Git so the AI always has a place to write its plans!*
