# 🛡️ Craft Floor & Anti-Slop Quality Standards

The **Craft Floor** is the non-negotiable quality baseline for every interface designed or modified by Impeccable. Load and enforce these checks on the rendered result.

---

## 1. The Verification Checklist (Verify)

Every UI edit must be verified against these dimensions in batched passes:

- **Contrast**:
  - Body text and form placeholders: ≥ 4.5:1 WCAG AA contrast.
  - Large display text: ≥ 3:1 contrast.
  - On colored surfaces, ALWAYS tint secondary text using the background hue or foreground; NEVER use default desaturated gray on saturated surfaces.
- **Depth & Elevation**:
  - Shadows must carry a physical offset (`y > 0`) and soft gaussian blur.
  - Zero-offset colored halos are cheap decoration, not physical elevation.
- **Spacing Rhythm**:
  - Tight spatial grouping for related elements; generous separation between distinct blocks.
  - Spacing rule: ALWAYS provide significantly more space *above* a heading than *below* it.
- **Typography**:
  - Reading measure: 65–75 characters per line (`max-width: 65ch–75ch`).
  - Display headers: max 6rem, balanced lines (`text-wrap: balance`).
  - Tracking floor: letter-spacing should not drop below `-0.04em`.
  - Obvious, intentional size and weight steps (no ambiguous 14px vs 15px steps).
- **Motion & Physics**:
  - Exactly one authored hero moment per view, not scattered chaotic effects on every single section.
  - Exponential ease-out transitions from an already-visible default state (120ms–240ms).
  - Reach beyond bare transform and opacity: smooth backdrop-filter, clip-path, and shadow transitions belong in the palette.
- **Interactive States**:
  - Every interactive element must define 6 states: Default, Hover, Active/Pressed, Focused (visible keyboard ring), Disabled, and Loading/Error.
- **Browser Surfaces (The 1% Detail)**:
  - Theme native browser defaults from the product palette:
    - Text selection background and color (`::selection`).
    - Input caret color (`caret-color`).
    - Custom scrollbar track and thumb (`scrollbar-color` / `::-webkit-scrollbar`).
    - Distinctive keyboard focus ring (`:focus-visible`).
    - Number alignment in tabular data (`font-variant-numeric: tabular-nums`).
- **UX Copy**:
  - Controls name their exact action (e.g. "Export CSV", not "Submit").
  - Errors name the problem and provide an immediate actionable recovery path.

## 2. The Refuse / Anti-Slop Ban List

These represent common AI design clichés and tropes that scream "generated by an LLM without taste":

1. **Cardocalypse**:
   - Ban nesting cards inside cards inside cards.
   - Ban using identical-sized cards (icon + heading + paragraph) as the sole scaffold of a page.
2. **Kickers / Eyebrows Above Headings**:
   - Ban small, uppercase, spaced-out category labels above headings (e.g. `FEATURES` above `What you get`). Let the heading speak for itself.
3. **The Hero-Metric Formula**:
   - Ban the generic 3-column metric template (huge bold number, tiny gray label, random percentage badge) unless actual audited data exists.
4. **Inter Everywhere**:
   - Ban defaulting blindly to Inter, Roboto, or Arial for every project. Select distinctive, intentional typefaces that reflect the product's character.
5. **Purple-to-Blue Lazy Gradients**:
   - Ban default saturated purple-to-blue linear gradients on hero buttons, headings, and card backgrounds.
6. **Untinted Grays & Pure Blacks**:
   - Ban pure `#000000` text or backgrounds; ban pure neutral `#808080`. Always warm or cool the neutrals by tinting with brand hues.
7. **Decorative Grid Backgrounds**:
   - Ban synthetic grid-line patterns unless the interface is an actual CAD canvas, architectural tool, or map.
8. **Side-Tab Border Clichés**:
   - Ban putting a 4px colored border on the left side of cards when they are not alerts or notifications.
9. **Hairline Border with Wide Fuzzy Shadow**:
   - Ban combining a 1px stark border with an oversized fuzzy black shadow on the same card. Choose either a crisp border or physical elevation.
10. **Extreme Blob Radii**:
    - Ban 44px+ pill radii on square or rectangular content cards.
11. **Crude SVG Mascots**:
    - Ban low-effort hand-drawn SVG doodles or generic corporate isometric vector clip-art. Use curated typography, photography, or intentional geometry instead.
12. **Bounce / Elastic Spring Abuse**:
    - Ban jarring bounce/elastic keyframe animations on hover or modal entry. Use clean, snappy damping.
