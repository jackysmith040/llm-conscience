# Dynamic visualization patterns

Select the pattern that matches the target mechanism. Motion must carry meaning.

## Build-up

Start with an empty or minimal system. Add components one at a time and show what each contributes. Use for architectures, layered models, proofs, and assembled systems.

## Flow-through

Show an input crossing boundaries and becoming an output. Keep the path visible and label transformations. Use for data, energy, matter, requests, arguments, and procedures.

## State transition

Freeze state A, name what is present, animate one causal change, then freeze state B. State what changed and what stayed fixed. Use for algorithms, chemistry, physics, law, and conceptual change.

## Branching decision

Show a decision point, the condition, and the consequences of each branch. Include failure or recovery branches. Use for algorithms, diagnosis, strategy, and procedures.

## Replication and scaling

Show one instance becoming multiple instances and identify what is shared versus independent. Use for systems, populations, sampling, deployment, and repeated structure.

## Replacement and update

Show an old state, the update input, the transition boundary, and the resulting new state. Use for software versions, biological turnover, policy changes, and iterative design.

## Feedback loop

Show output returning as a new input. Mark delay, amplification, damping, and stability where relevant. Use for control systems, learning, markets, ecosystems, and social processes.

## Freeze-and-animate

Keep all irrelevant objects still and animate only the variable or relationship under discussion. Use when motion risks overload or when isolating causality.

## Counterexample and failure mode

Show the normal mechanism, remove one assumption, and animate the failure. State the exact assumption that mattered.

## Required storyboard fields

For each scene specify: scene ID, objective, starting state, stable objects, changing object, transition, end state, labels, narration, timing, pause, source basis, learning layer, expected learner response, and validation check.
