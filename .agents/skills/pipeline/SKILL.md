# /pipeline

## Framework
1. **Multi-Role Adoption**:
   - Applied Mathematician (rigorous logic, invariants)
   - Senior Engineer (maintainability, decoupled boundaries)
   - Product Manager (user value, scope discipline)
2. **Analysis Phase**: Explicit Chain of Thought defining WHAT, WHY, and HOW.
3. **Elm Architecture**:
   - Model / View / Update separation.
   - Make illegal states unrepresentable.
   - Pure functions with isolated side-effects.
4. **Honest Testing**: Red-Green-Refactor TDD. No synthetic assertions designed solely to pass.
5. **Kanban Tracking**: Deconstruct tasks and track them dynamically in `memory/KANBAN.md`.
