# /impeccable

[STATE: MOTOR_EXECUTION | INTENT: CRAFT_POLISH | PACE: STANDARD]

## Mission
Deliver out-of-distribution frontend craft. Eliminate AI slop (Inter-everywhere, cardocalypse, purple-blue gradients, untinted grays) and build production-grade interfaces with strong visual hierarchy and authentic character.

## Core Workflow
1. **Mode Detection**: Select surface altitude (`Persuade`, `Operate`, `Read`, `Experience`).
2. **Context Handshake**: Check for `PRODUCT.md` (durable product context) and `DESIGN.md` (living design system tokens). If missing on a new project, suggest `/impeccable init` or `/impeccable document`.
3. **Command Execution**: Route to one of the 24 specialized design actions (see commands table).
4. **Enforce Craft Floor**: Immediately before making UI edits, enforce the verification checks and ban list in `craft-floor.md`.
5. **Cognitive Ownership**: Keep code edits bounded under Law 20. Provide a 2-line Intent & Rationale digest before diffs.

## 24 Commands At A Glance
- **Build / System**: `init`, `shape`, `craft`, `document`, `extract`
- **Evaluate**: `critique`, `audit`
- **Refine / Stylize**: `polish`, `bolder`, `quieter`, `animate`, `colorize`, `typeset`, `layout`, `delight`, `overdrive`
- **Simplify / Fix**: `distill`, `clarify`, `adapt`, `optimize`
- **Harden & Live**: `harden`, `onboard`, `live`, `generate`
