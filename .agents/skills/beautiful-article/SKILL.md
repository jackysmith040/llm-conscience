# Beautiful Article Skill

[STATE: MOTOR_EXECUTION | INTENT: CRAFT_POLISH | PACE: STANDARD]

## Goal & Standards
Transform raw text or notes into a single-file, production-grade HTML article that is beautiful to read, fully responsive, and offline-shareable.

## Core Design Rules
1. **Single-File Delivery**: All CSS, fonts, and inline SVG assets bundled in one `.html` file.
2. **Reading Typography**: 
   - Body font size: 18–20px with 1.6–1.75 line-height for optimal readability.
   - Max measure: 65–75 characters per line (`max-width: 680px–740px`).
   - High-contrast accessible color palette with clean dark-mode support via CSS variables.
3. **Editorial Elements**:
   - Distinctive typography hierarchy (display headers, lead paragraphs, pull quotes).
   - Polished callouts (`aside` / blockquotes) with subtle border-left tints.
   - Elegant code syntax styling and responsive tabular data.
